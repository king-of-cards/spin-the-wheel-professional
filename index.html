Rules

Turn the wheel off between campaigns: customers still see the form, but the spin screen tells them it's closed. Set the admin login endpoint to require a real username/password checked against your server instead of the passcode below. The passcode is a fallback only — it's a soft lock, not real security, since anyone with the file could read the source and bypass it.
